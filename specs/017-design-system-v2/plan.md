## Contrats
- **`SceneTheme`** reste l'unique `ThemeExtension` (RG-09) ; ses rôles sont **figés dès T11/T12** (aucun rôle ajouté plus tard : chaque ajout obligerait à régénérer les tokens). Correspondance : `background` = `void`, `surface` = `surface-100`, `textPrimary` = `ink`, `textSecondary` = `ink-muted`, `accent` = `signal`, `ok/risk/blocking Background` = `go/warn/nogo-ghost`, `ok/risk/blocking Foreground` = `go/warn/nogo`, `neutralBackground` = `surface-300`, `neutralForeground` = `ink-muted`, `highlightOutline` = `signal`, `actionNeutralBorder` = `ink-muted` (pas `line-strong` : 2,30 à 2,44:1), `actionDangerBorder` = `nogo`, `agentWorking` = `signal`, `agentIdle` = `ink-faint`, `agentRejected` = `warn`, `agentInterrupted` = `baseline`, `chartIos` = `ink`, `chartAndroid` = `signal`, `chartOther` = `baseline`. Champs ajoutés : `panelTop` (`surface-200`), `line`, `lineStrong`, `inkFaint`, `plasma`, `plasmaGhost`, `signalGhost`, `orbVeil`, `surface300`, `surface200`, `data`, `verdict`, `transcript`, `button` (`TextStyle`). `onNogo` n'est pas ajouté.
- **Tokens (T11, générateur étendu)**. `build_tokens.mjs` et `tokens_parity_test` savent aujourd'hui exprimer des couleurs à 6 chiffres, des dimensions, des durées, des nombres à une décimale et des graisses. T11 ajoute : (1) **couleurs DTCG 2025.10 avec `alpha`** (les `*-ghost`), le test vérifiant `round(alpha × 255)` contre l'octet de la source ; (2) `shadow` → `List<BoxShadow>` constante, `inset: true` refusé ; (3) `cubicBezier` → `Cubic` ; (4) `fontFamily` ; (5) interlettrage en **px calculé** à la taille 017 ; (6) nombres émis **sans arrondi** (`toFixed(1)` écrasait 1,333 et 1,143) ; (7) imports `flutter/painting.dart` pour `BoxShadow`/`Cubic`/`Offset`. **Règle de flou écrite dans le générateur** : le flou CSS `B` donne σ = B/2 ; `BoxShadow.blurRadius = r` donne σ = 0,57735 r + 0,5, donc r = (B/2 − 0,5) / 0,57735. L'ombre `inset` de `panel` devient le filet de 1 px peint par `ScenePanel`. La source `tokens.json` du design system n'est pas du DTCG (listes `name`/`value`) : elle est **transcrite** dans `tokens/*.tokens.json`.
- **Façades**. `SceneTokens` reste interne au paquet (absent du barrel, pour que les slices n'aient pas la palette brute ; RG-09). Les espacements, rayons, ombres et durées sortent par `SceneSpace`, `SceneRadius`, `SceneShadow`, `SceneMotion` (même forme que `SceneMotion` aujourd'hui).
- **Polices**. Familles `Space Grotesk` et `JetBrains Mono` déclarées **sans préfixe** dans le `pubspec.yaml` du paquet (`Space Grotesk`, `JetBrains Mono`, `DejaVu Sans`) : Flutter pose lui-même `packages/shared_design_system/` dans le `FontManifest` (vérifié par `flutter build bundle` en T10 ; nommer la famille avec le préfixe donnerait un double préfixe). Les styles utilisent les noms **préfixés** (`SceneFonts.sans`, `.mono`, `.fallback`) **sans** le paramètre `package:` des `TextStyle`, qui préfixerait aussi `fontFamilyFallback` et le neutraliserait ; chaque style liste explicitement `SceneFonts.fallback` (DejaVu Sans) pour ✓ ▲ ▶ ↺ ◆ ★ et U+202F, absents des deux polices. `fontWeight` = `wght` dans chaque style (assistant unique `sceneWeight`, appliqué aussi au `textTheme` de Material) ; `FontFeature.tabularFigures()` sur `data`/`value`. Aucune dépendance `google_fonts` ; aucun téléchargement à la construction. Licences OFL enregistrées par `registerSceneFontLicenses()` dans `main()`.
- **Mouvement**. `SceneMotion` garde son interface ; seules les valeurs changent (U2) ; `curve` = `Cubic(.2, .8, .2, 1)`. **Toutes les boucles** passent par `SceneMotionScope.loop` (battement de Bloquant 1,6 s, cadre de génération `gc-spin` 2,8 s / `gc-scan` 2,2 s, squelette, orbe) avec leurs durées en tokens, chacune dans son `RepaintBoundary` local ; `TopBar` est posée sous le `SceneMotionScope` de la page.
- **Peinture**. `ScenePanel` est une **couche décorative sœur** : `Stack[RepaintBoundary(ScenePanelDecoration), RepaintBoundary(ClipRect(contenu animé)), contour de surbrillance]`, statique dès le squelette (seul le contenu bouge avec `gc-rise`) ; sa marge est un **paramètre** (16 px, valeur actuelle, pour les cellules de la grille ; le bandeau de 72 px, le rail de 96 px et la rangée basse gardent leurs marges). Le panneau est en retrait de 4 px dans la cellule (U1). Le contour de surbrillance prend le rayon 16. Le fond de points est dessiné en un seul `drawPoints` (ou `ImageShader` répété), dans la frontière de capture de la page. Halos `glow-*` seulement à l'état actif (génération, voix qui parle) ; **pas de glow « bouton armé »** (cet état n'existe pas dans `action_bar.dart`).
- **Statuts**. `DsStatusChip.measure(context, status, label)` expose la géométrie de la puce ; `release_checklist.dart` l'appelle au lieu de recalculer `horizontalPadding`/`verticalPadding`.

## Risques
| Risque | Parade ou test qui le couvre |
|---|---|
| Une police **variable** ne rend pas les graisses sous Flutter Linux, ou un `fontWeight` sans `FontVariation` donne un faux gras | T10 mesure l'**encre** des glyphes (pixels via `toImage` sous `runAsync`) pour les deux familles : `wght` 700 seul, `wght` 700 avec `w700`, `w700` seul ; le test de largeur est inutile pour la police à chasse fixe ; règle testée : `fontWeight` = `wght` partout ; **capture `app-smoke` d'une échelle de graisses dans T10**, avant T11 (le moteur sous Xvfb peut différer de la machine de démo : à revérifier en J7) ; repli : instances statiques générées avec `fonttools`, après vérification de l'absence de nom de police réservé dans l'OFL |
| Glyphes manquants (✓ ▲ ▶ ↺ ◆ ★ · − ≥, espace fine insécable, accents) | T10 teste les glyphes de l'app et des fixtures ; repli `DejaVu Sans` embarqué |
| Les polices réelles changent la largeur des textes et font tronquer ou déborder des cellules (D-02 à D-05) | `loadRealFonts` charge les polices de l'app avant de rejouer D-01…D-07 ; `paragraphsTruncated` détecte l'ellipse ; **chaque tâche T12b, T14, T16 à T19 lance `flutter test test/acceptance/acte_design_ergonomie_test.dart` avant de committer** (la porte `--unit` exclut l'acceptation) |
| `kpi-xl` 76 px déborde la cellule de 302 px | test de hauteur des cellules (013) ; taille réduite au plus juste, consignée |
| Ombres, dégradés, grille et boucles pèsent sur NFR-04 | décoration statique en couche sœur, `RepaintBoundary` locaux, grille en `drawPoints`, halo d'orbe en dégradé radial ; `canvas_board_rebuild_test` reste vert ; mesure des 60 i/s en répétition (J7) |
| `pumpAndSettle` ne converge plus avec une boucle active | inventaire des tests concernés (T13) ; test « `pumpAndSettle` converge sous `disabled` » |
| Contraste des fonds `*-ghost` | `Color.alphaBlend` sur chaque fond réel (`void`, `surface-100`, `surface-200`, `surface-300`) ; seuil 4,5 pour les mots de statut. Relevé de la revue : `nogo` sur `nogo-ghost` 5,10:1 (`surface-200`) et 4,54:1 (`surface-300`) ; `ink-faint` 3,79:1 et 3,40:1 (grand texte, 3:1) ; `line-strong` sur `surface-100` 2,30:1, **pas 3:1 comme l'affirme la source** : jamais la seule frontière d'un bouton ni l'anneau de focus (le focus `signal` convient), écart consigné dans `status.md` |
| Node absent ou version différente pour régénérer les tokens | Node 26.12.1 présent ; Style Dictionary 5.7.1 épinglé avec `package-lock.json` ; sinon `Bloquée`, pas de contournement à la main |
| Intégrité des polices | URL épinglée sur un commit de `google/fonts` ; SHA-256 dans `assets/fonts/README.md` et `LICENSES.md` (même modèle que `testing/real_fonts/fonts/`) ; un test unitaire recalcule les empreintes ; le build ne télécharge rien |
| Une couleur ou une famille codée en dur échappe au thème | `no_hardcoded_style_test` (architecture) interdit `Color(0x`, `Colors.`, `Color.fromARGB`, `Color.fromRGBO` et `fontFamily:` dans `lib/` hors du paquet de design |
