# PDR-0034 — Nom de l'app fictive : Release Copilot

Part de l'assistant : consignation.

## Contexte
- Fiche § 3 : « une app mobile (nom à choisir) » (Q-08).

## Hypothèses
- Aucune.

## Options
1. **Release Copilot** (retenue)

## Décision
- Le jeu de données, les surfaces et la voix nomment l'app « Release Copilot ».

## Raisons
- Parole du porteur (2026-10-29), Q-08 : « Release Copilot ».

## Options écartées
- Aucune alternative proposée.
