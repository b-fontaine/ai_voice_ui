Corriger : `context.WithTimeout(ctx, GuardTimeout)` passé à `Close` puis attente de `done` sur le même contexte ; `Shutdown` en parallèle ; `main.go:81` contexte borné ; documenter `port.Sideband.Close`. Tests : `TestCloseGuardTimeoutWithBlockingSideband`, `TestShutdownParallelGuard`.
- [x] **R2 importante** — sessions OpenAI laissées ouvertes (coût, NFR-11) : `Hangup(ctx, id)` dans `port.LiveProvider` + `openailive` (`client.Live.Sessions.Hangup`), appelé si `Sideband` échoue après `CreateSession` et sur coupure sans `session.closed` ; `LiveEvent.Reason` ; `NewMeter` validé dans `NewService` ; `Options.MaxSession` (`VOICE_MAX_SESSION`) ; `delete(s.sessions, id)` en fin de supervision.
